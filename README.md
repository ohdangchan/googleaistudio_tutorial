# googleaistudio_tutorial

Google AI Studio 및 Gemini API 활용 튜토리얼 저장소입니다.

## 📁 튜토리얼 및 서비스 목록

- **[ai_youtube_search/](ai_youtube_search/)**: Wix Film & TV 프로덕션 레이아웃 기반의 **AI 유튜브 영상 검색기**. YouTube IFrame 임베드, 볼륨 조절, `gemini-3.5-transcribe` 오디오 타임스탬프 추출, `gemini-3.8-flash` 기반 영상 Q&A 및 특정 내용 위치 탐색 후 자동 이동/재생(Play) 지원
- **[youtube_stt_service/](youtube_stt_service/)**: 유튜브 영상 URL 입력 시 오디오 다운로드 및 Gemini 3.5 Transcribe 기반 실시간 다국어(한국어, 영어, 일본어, 중국어, 러시아어, 스페인어, 프랑스어, 독일어, 인도어, 동남아어) 화자 분리 트랜스크립트 추출 웹 서비스
- **[gemini_35_stt_example/](gemini_35_stt_example/)**: `gemini-3.5-transcribe` 모델을 활용한 실시간 스트리밍 음성 인식(STT), 화자 분리(Diarization), 단어별 타임스탬프 추출 예제
- **[gemini_tts_example/](gemini_tts_example/)**: `gemini-3.1-flash-tts-preview` 모델을 활용한 다중 화자(Multi-Speaker) 음성 합성(TTS) 및 WAV 포맷 변환 예제
